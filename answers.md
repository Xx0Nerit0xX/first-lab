# Відповіді на питання для самоконтролю

## 1. Чому важливо вказувати user.name та user.email?

Git записує ці дані в кожен коміт як інформацію про автора. Завдяки цьому в історії видно, хто зробив зміни, а GitHub за email зіставляє коміти з обліковим записом. Без цих налаштувань Git не зможе коректно створити коміт.

## 2. Яка різниця між git pull і git fetch?

- `git fetch` тільки завантажує нові коміти з віддаленого репозиторію, не змінюючи робочі файли та поточну гілку.
- `git pull` = `git fetch` + злиття (merge) отриманих змін у поточну гілку, тобто файли оновлюються.

## 3. Як скасувати останній коміт, не втрачаючи зміни у файлах?

```bash
git reset --soft HEAD~1
```

Коміт скасовується, а зміни залишаються у файлах і в індексі (staged). Команда `git reset HEAD~1` також зберігає зміни у файлах, але прибирає їх з індексу.
